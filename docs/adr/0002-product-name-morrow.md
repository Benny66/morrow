# 产品命名为 Morrow，并与宠物角色名分离

`my-notice` 是脚手架实例化时的占位名，语义泛、不可检索，也不承载产品气质。产品核心是「提醒 + 桌面宠物 + 打卡生长」，需要一个独立品牌名。语义最贴切的候选是 Kairos（希腊语「恰当时机」），但效率/待办赛道已有多个同名应用（如 App Store 的 Kairos Tasks、Kairos - Journal/Task Tracker），`kairos.com` / `kairos.app` 也已注册。最终选择 Morrow（古英语「明日 / 次日」）：与「接下来该做什么」的提醒语义自然衔接，读音与拼写对中文用户友好，公开检索未发现提醒类同名应用。

宠物角色「小满」已有完整设定，且其节气语义（麦粒渐满、不求大满）与芽的生长绑定。产品名与角色名分离：Morrow 是产品，小满只做宠物，不以小满代指产品。

## 备选方案

- **产品名 = 小满**：品牌资产最集中，但「小满」是常见词/节气名，检索与商标辨识度弱，且产品与角色耦合。
- **Kairos**：语义最贴切，但同名应用集中在效率赛道，品牌搜索被稀释，域名也已被占。
- **保留 my-notice**：零成本，但占位名无法承担品牌与检索。

## 后果

- 改名波及 Go module/imports、前端 bindings 目录、bundle id、数据目录、脚本与文档；当前无 git remote、无外部用户，可以干净切换。
- macOS bundle id 固定为 `io.github.bennywen.morrow`；此后变更会重置登录项与权限授予。
- 应用显示名统一为 `Morrow`，中文只出现在描述与 README；数据目录与数据库文件分别为 `Morrow/`、`Morrow.db`。
- 旧数据不做代码内自动迁移，手动复制目录并把 `my-notice.db` 改名为 `Morrow.db`。
- 宠物名「小满」、形象与图标设计不变。
