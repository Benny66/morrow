# P1 系统专注与日历只读忙闲状态

P1 的系统专注联动与日历感知只读取布尔状态：系统专注是否开启、当前日历是否处于忙碌。不读取事件标题、参与人、备注、地点或任何日历内容；不落盘、不上传。两者默认关闭，由用户在设置中显式开启并授权；拒绝授权时静默降级，不影响提醒主流程。

## 备选方案

- **读取事件标题生成暂停文案**：更贴心，但日历内容敏感，且宠物/菜单栏只需要判断「是否该暂停」，不需要知道会议主题。收益小、隐私成本高。
- **不做系统级读取**：避开权限与平台适配，但专注模式下的手动静音无法自动感知，且与会议应用名单重叠但覆盖不全。
- **可选授权、默认开启**：首次启动即请求权限，转化更高，但违背「本地优先、无感」的信任预期；改为默认关闭、显式开启。

## 后果

- macOS 专注状态通过系统公开的 Focus 状态接口读取（需要用户授权）；日历通过系统日历权限读取忙闲。Windows 若没有等价公开能力，P1 允许只做 macOS，Windows 保持会议应用识别。
- 日历只回答「此刻是否忙」，不参与计划生成，也不进入 AI 提示词。
- 权限被拒绝或系统接口不可用时，智能免打扰继续依赖空闲、会议应用与全屏信号；不弹二次请求。
