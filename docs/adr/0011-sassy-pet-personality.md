# 宠物的默认人格转为毒舌健康搭子

Morrow 原先的宠物定位是温和陪伴。产品决定把默认人格改为「毒舌健康搭子」：小满以损友式、有话直说的口吻点评久坐与统计，允许吐槽任何统计（包括应用类别、跳过次数与效率），以换取更强的人格记忆点与差异化。设置提供毒舌 / 活泼 / 温和三档，默认毒舌；气泡内提供「别这样说」立即切到温和并记住偏好。

## 安全底线（不参与人格设定）

- 不得攻击外貌、智力、心理状态、家庭或健康状况，不得做医疗诊断，不得阻止用户就医。
- 任何毒舌都必须给出一个可执行的台阶（起来走走、再坐十分钟、今天先这样等），不能只有羞辱。
- 毒舌只影响措辞，不改变提醒的投递规则、统计口径与隐私边界。

## 备选方案

- **默认温和、毒舌可选**：品牌风险最低，但用户明确选择了默认毒舌，故未采用。
- **首次引导让人格二选一**：选择即知情，但会拉长首次引导，且新用户未必能预判毒舌强度。
- **隐藏彩蛋式毒舌**：有惊喜感，但用户无法预期何时被吐槽，反而更不可控。

## 后果

- `CONTEXT.md`、README 与对外文案需要从「温和陪伴」改为「毒舌健康搭子」，否则文档与产品人格自相矛盾。
- 默认毒舌会提高首次使用的冒犯与卸载风险；必须保留显眼的切档入口，并对文案做真人审校。
- 「不做愧疚式提醒」的旧定位不再成立；新的底线是「可以毒行为与统计，不否定人格、不做健康判断」。
