# 小满 — 内置宠物形象

> 实现：`frontend/src/views/Pet.vue`（唯一真相）。
> 评审快照：`docs/pet/character-sheet.html`（静态设计稿，不参与运行）。

## 定位

桌面宠物是**提醒的化身**，不是装饰。它只负责情绪与注意力，说话的是气泡；
所以形象的第一诉求不是"可爱"，而是"在被提醒的那一秒，你能一眼看出它的状态"。

## 为什么是「一滴水 + 一株芽」

- **水**：产品最核心的提醒场景就是喝水。用形象直接承载场景，比任何吉祥物都短一条推理链。
- **芽**：打卡是长期习惯，"长出来"比"打勾"更像收益。水养芽，两件事合成一个隐喻。
- **芽在头顶**：它是天然的情绪指示器。等待时立起抖动、庆祝时大幅甩动——
  这比改脸更有效，因为**脸的表情要 192px 以上才看得清，头顶的动势在 96px 就成立**。
- **不用铃铛**：铃铛已经是应用图标（`build/appicon.svg`）。图标是品牌符号，角色是陪伴，
  两者分工，避免"图标和宠物长得一样"的冗余。

## 造型语言

- 单一水滴轮廓，无描边，靠色块 + 一处高光分层。小尺寸下只留剪影也成立。
- 两只短手用**圆头粗线段**画，关节藏在身体里，所以挥手时看不到接缝。
- 表情两套（睁眼 / 弯眼）常驻 DOM，用透明度切换，不新增条件渲染分支。

## 状态（对应 `PetAnim` 的四个值）

| 状态 | 触发 | 身体 | 芽 | 眼睛 |
|---|---|---|---|---|
| `idle` | 无待处理 | 呼吸 3.4s | 轻摇 ±2.5° | 睁眼 + 眨眼 |
| `waiting` | 有待处理提醒 | 呼吸提速到 1.5s | 立起 + 小幅抖动 | 睁眼 |
| `waving` | 点击宠物 | 摇摆 ±5°，两轮 | 轻摇 | 弯眼（笑） |
| `jumping` | 待处理清空 | 起跳 520ms 循环 | 大幅甩 ±10° | 弯眼（笑） |

> `running` / `running-right` / `running-left` / `review` / `failed` 五个值来自
> codexpet 图集的 9 行约定（外部规格，见 `lib/pet.ts`），builtin 形象不实现它们——
> 那几个动作需要逐帧素材，程序化 CSS 做不出可信的跑步循环。状态机目前也不会切到它们。

### 待机行为（不属于 `PetAnim`）

下面三种都不写 `anim`、不参与气泡优先级——它们是**叠加在待机之上的动作**或**独立的形态层**。
并进 `PetAnim` 会污染 `setAnim` 的保持时长与优先级链（`PetAnim` 的取值是图集行序，
属于状态语义）。

| 行为 | 触发 | 表现 | 约束 |
|---|---|---|---|
| 微动作 | 空闲时 40–90s 随机一次 | 张望（两眼左右移）/ 伸懒腰（纵向拉长 6%）/ 理芽（左叶抖）/ 打哈欠（张嘴+闭眼） | 单次 ≤1.2s；待处理、暂停、演示、气泡在场、贴边收起、减弱动态时一律不演 |
| 打盹 | 暂停原因为空闲/锁屏且持续 8 分钟 | 闭眼、芽收拢、呼吸放慢到 6.4s 一轮 | 有待处理时不睡；贴边收起时不睡（无观众） |
| 惊醒 | 打盹中鼠标进入 / 暂停解除 / 出现待处理 | 眼睛放大 + 芽弹起，300ms | 幂等：同一次醒来只播一遍 |

只对 builtin 实现微动作。sprite 模式的图集只有 9 行固定动作，硬塞微动作会错行；
它的打盹慢节奏由 `loop()` 的 `PET_SLEEP_FPS` 负责，醒来时用 `jumping` 行播一次短回执。

### 形态与神态：两条轨道

芽的**形态**（大小、叶展开角）与**今日神态**（高光透明度、是否轻垂）分开：

- **形态 = max(高水位, 长期档)**：长期档由「累计完成天数」映射 0–4 档；
  高水位只增不减，跨天、断签、换场景都不会缩。
- **高水位只播种一次**：从旧版本升级后的首次运行取 `max(长期档, 今日档)`，
  保留老版本按今日完成率显示的效果，避免升级当天芽突然变小。
  之后今日档不再参与形态；全新安装从 0 开始，不参考今日档。
- **今日 = 神态**：今日完成率只改高光与轻垂，**永远不碰 `scale`**。
  否则又会回到"每天早上缩小一次"的老问题；今日档高于长期档时也必须守住这一条。
- **没安排不是失败**：没有启用目标时 `has_target=false`，神态保持中性，不显示蔫态。

判定全在 `internal/service/growth.go`（`longTermStage` / `composePetShape` / `growthStage`），
高水位的持久化在 `App.GetPetGrowth`，前端只做"整数 → class"。

### 久坐情绪（builtin）

久坐快照的 `mood` 三态（精神 / 有点担心 / 芽耷拉了）通过
`.pet--sit-energetic` / `.pet--sit-concerned` / `.pet--sit-droopy` 只作用于头顶芽，
不改变 `PetAnim` 的待机/等待/挥手/庆祝状态；有待处理、暂停或更高优先级气泡时，
情绪层让位。芽耷拉已实现，不再属于扩展钩子。

### 镜像：它在跟着你（builtin + sprite）

小满会跟着「你此刻在做什么」改变体态。它不是按键镜像（那是 BongoCat 的做法，
需要「输入监控」授权），而是**类别镜像**：久坐感知每 5 秒读一次前台应用，
映射成六类行为（写代码 / 做设计 / 浏览 / 沟通 / 影音 / 其他），
只把**类别与活跃档位**送进宠物窗口——不送应用名、不送窗口标题。

| 姿态 | 触发类别 | builtin 表现 | sprite 表现 |
|---|---|---|---|
| `working` | coding / design | 坐低 10px + 缩到 93% + 侧压 4°，双手小幅起落 | 换用 `review` 行（此前从未被触达的第 7 行） |
| `listening` | communication | 向我这边倾 9° + 侧移 6px + 一只手绕肩抬起 45°（托腮的静态近似） | 保持待机行（图集没有"听"这一行） |
| `watching` | browsing / media | 横向放大 10% + 纵向压扁 7%（"趴着看"）+ 眼睛睁大 15% | 保持待机行 |

**轮廓差异是验收标准，不是审美偏好。** 96px 下相对待机的实测（0.5 倍截图，**先冻结呼吸**再量——
呼吸是 `.pet__svg` 上的 scale 循环，抓图相位随机，会让包围盒抖 ±3%，而姿态差异本来就在 5–12% 量级）：

| 姿态 | 宽 | 高 | 长宽比 | 其它 |
|---|---|---|---|---|
| `working` | −6% | **−11%** | 0.70→0.74 | 重心下移 6px（CSS） |
| `listening` | +3% | −2% | 0.70→0.73 | 包围盒几乎不变：它的线索是**朝向**——芽尖水平偏移 +19.7px（待机 +12）、右臂抬到肩线以上 |
| `watching` | **+10%** | −7% | 0.70→**0.83** | 眼睛放大 15% |

低于 ~5% 且没有方向性差异的变化，在这种尺寸下看不见——第一版（2–3px、1.5°）就是反例。
`listening` 说明一件事：**包围盒不是唯一判据**，倾斜类姿态要靠"顶端偏移 / 手臂位置"看。

**幅度是按「96px 高的宠物」校准的，不要凭感觉调小。** `pet_scale` 常见取值是 0.5，
此时宠物在屏幕上只有 96×104——第一版用 2–3px 位移与 1.5° 旋转，换算到屏幕只剩 1–1.5px，
用户看到的是"完全没反应"。另有一条硬约束：画板 192×208 里芽尖在 y≈7、阴影在 y≈194，
**上方几乎没有余量**，所以"抬头/站高"这类姿态在这套素材上做不出来，只能用"坐低 + 缩放 + 倾斜"。

四条约束（改之前先读）：

1. **镜像永不写 `anim`**：它只是「待机该画哪一行 / 挂哪个 class」的替身。
   待处理、庆祝、挥手、惊醒、打盹改的都是 `anim` 或门控，天然优先；
   也因此镜像不可能推迟任何一条健康提醒。
2. **进入慢、退出快**：进入要连续 3 次轮询确认 + 换过之后 20 秒内不再换
   （防止在两块屏之间来回切时姿态抽搐）；任一压制条件成立则**立即**清空。
   这三条时序写在 `lib/pet.ts` 的 `advanceMirror()` 纯函数里，由 `make e2e-pet`
   的 7 条断言钉住（确认窗口 / 抖动不切 / 最小停留 / 立即清除 / 变 other / 挥手让位 ×2）——
   它们错了都不会报错，只能靠断言。
3. **与微动作共存，而不是互斥**：CSS animation 会整段覆盖同一元素的静态 transform，
   所以只把「抢同一元素」的微动作从随机池里剔掉（`stretch` 抢身体层、
   `watching` 时 `look` 抢眼睛层），其余照演。镜像整天生效，禁演等于让宠物变死。
   姿态切换会写一行 `镜像姿态已切换` 的前端日志——它是"没反应"时唯一的证据。
4. **只有"有迹象"时才演**：人离开键盘超过 3 分钟（`away`）就不演了——
   不知道你在做什么时，不假装知道。

**挥手时镜像让位**：`.pet--mirror-*` 的手臂规则都带 `:not(.pet--waving)`。
镜像的样式写在 `Pet.vue` 更后面，同优先级下会盖掉 `.pet--waving .pet__arm--right`——
症状是"点了宠物不挥手"且不报错。对应断言直接读 `getComputedStyle(arm).animationName`。

**开关就是应用画像**：没有独立开关。关掉应用画像，宠物就不再跟随你的活动。
开会（Zoom/腾讯会议等）会触发智能免打扰，宠物的 `paused` 为真，镜像随即清空——
所以 `listening` 的真实场景是打字聊天，不是开会。（注意拦住它的**不是**"没有类别"：
前台采样并不排除会议状态，是前端门控挡下的。）

非工作时段（没有启用的站立/走动提醒、或不在其时间窗内）不做前台采样，
镜像也随之不存在。这是既有采样的边界，不是本节的 bug。

### 减弱动态效果（`prefers-reduced-motion`）

只停**常驻循环**（呼吸、摇芽、眨眼、等待抖动），保留**事件触发的瞬时反馈**（挥手、庆祝）。
理由：前者是这类用户真正想关掉的东西（一个 24 小时在呼吸的常驻小窗），
后者是"我处理完了"的唯一视觉回执，停掉就只剩文字。
实现靠 specificity 分层（`.pet--waving` / `.pet--jumping` 的规则高于媒体查询里的重置），
改选择器时不要顺手把这两条写进同一个层级。

## 色彩

全部走设计令牌，不新增颜色、不写死 hex（前端护栏会拦）：

| 元素 | 令牌 |
|---|---|
| 身体 / 手臂 | `--color-primary` |
| 高光 | `--color-primary-50` |
| 腮 | `--color-primary-300` |
| 眼 / 嘴 / 落地影 | `--color-primary-900` |
| 芽（茎 / 叶） | `--color-success`（健康 / 成长语义） |

换肤只改 `--color-primary`，角色自动跟着变——这也是它不引入专属色的原因。

## 人格与语气

小满默认是**毒舌健康搭子**，不是只会卖萌的装饰。它只吐槽久坐行为与统计，
可以拿时长、类别、休息次数、跳过/推迟、周对比开玩笑；不攻击外貌、智力、心理、
家庭或健康状况，不做医疗诊断，也不阻止用户就医。每个软提醒都必须给出可执行台阶。

三档语气只影响后续文案，不改变计时、统计与隐私边界：

- **毒舌（默认）**：直接、有梗，可以吐槽统计，但必须给台阶；
- **活泼**：轻快、鼓励，不否定人格；
- **温和**：只关心、不吐槽。

设置页可切换；气泡「更多 → 别这样说」会立即切到温和并持久化，同时给一句温和确认。
温和语气下不再显示「别这样说」。所有台词来自内置模板 + 变量，不调用 AI、不联网；
记忆只引用类别级事实与统计，绝不出现具体应用名。

## 记忆气泡

宠物可以独立冒一条记忆气泡：标题「小满记得」，正文只引用类别级事实与完整统计
（时段、星期、周对比、类别分钟、休息/跳过/推迟次数），绝不出现具体应用名或逐条流水。
动作是「知道了」「打开客户端」，更多里保留「今天先这样」「别这样说」。
记忆气泡与软提醒共享每天 5 次主动发言预算与至少 30 分钟间隔；专注、暂停、静默、
待处理、休息倒计时与用户输入中都不冒泡；过期未展示不计预算。

## 未实现的扩展钩子（有意留白）

1. **水位线**：身体里一条水线映射当天喝水进度。**刻意没做**——静态的半截水位
   会被读成"画错的肚皮"，必须接上真实数据才有意义。
2. **sprite 模式的待机微动作与打盹**：图集是外部约定（9 行固定动作），
   要做得先扩图集规格，不是改前端能解决的。

> 「芽随连续打卡生长」已在本轮实现，但不是原计划的 streak，而是「累计完成天数」——
> 理由见 `openspec/changes/pet-autonomy/design.md` 第 2 节：streak 断一天归零，
> 要保住单调性就得另存高水位；累计天数的单调性由查询本身保证。
