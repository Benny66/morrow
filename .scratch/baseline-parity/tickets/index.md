## 执行顺序

```
001（空闲检测 + 宠物/菜单栏状态）
  ├─ 002（锁屏 / 休眠）
  ├─ 003（会议应用前台）
  ├─ 004（全屏 + 屏幕录制权限）
  │    └─ 005（暂停设置界面，另依赖 002 / 003）
  │         └─ 006（错过提醒可见）
  └─ 010（P1 系统专注）
       └─ 011（P1 日历忙闲）
            └─ 012（P1 授权与降级）

007（休息模式核心，无阻塞）
  ├─ 008（预警 + 宠物陪做）
  └─ 013（护栏，另依赖 001）

009（多屏强提醒，无阻塞）
```

- 002 / 003 / 004 / 007 / 009 在 001 之后可并行。
- 005 依赖 001–004；006 依赖 001–004。
- 010 / 011 依赖 001；012 依赖 010、011。
- 013 依赖 001、007。

## 交付范围

P0：智能免打扰四路信号、场景化休息模式、菜单栏快捷入口、多屏强提醒、错过提醒可见。
P1：系统专注联动与日历忙闲感知（只读布尔、默认关闭、显式授权、拒绝降级）。
