# 全量验收与文档收口

**Blocked by**: 003、005、006

> 规格：全部用户故事；重点 US-38、US-39

## 目标

在旧库升级、导出导入、无场景/场景停用/静默/错过/推迟/强提醒/宠物等全链路上完成累积验收，并收口文档、护栏与静态检查。

## 涉及层

- [ ] 数据层
  - 旧 schema → 新 schema 迁移 fixture：`once=true`、周期项、打卡/fire 关联数据都不丢；`scenario_id` 可空生效。
  - 导出当前库 → 导入新版本；导入旧备份走同一迁移，不丢数据。
- [ ] 逻辑层
  - 累积审计：002 的核心链路（触发/错过/静默/场景停用/推迟补发）与 005 的 AI 链路（分类/日期/原子落库）一起复验。
  - 确认一次性项不写 CheckIn、不进入今日目标/连续天数/宠物；`pending_count` 包含一次性。
  - 确认没有新增事件常量、没有第二次实现的时间解析/校验逻辑。
- [ ] UI 层
  - 端到端走查（`make dev` + MCP/browser）：
    1. 空库/无场景：手动建一次性 → 即将到来 → 到点/错过 → 完成/跳过/推迟；
    2. 场景停用后一次性仍触发；静默时段内一次性仍通知；
    3. AI 文本「每天喝水；明天 4 点吃苹果」→ 混合草稿 → 编辑/取消勾选 → 原子保存；
    4. 粘贴截图 → 草稿 → 保存；无 Key 时手动路径；
    5. Plan 页 `interval=0` 每日单点；完成后次日继续；
    6. 强提醒窗口/宠物对一次性事件的响应。
- [ ] 测试与文档
  - `make test`、`make lint`、`make smoke` 全绿；绑定产物已重新生成，护栏无过期报警。
  - `docs/map.md` 补新入口/新文件导航；`CONTEXT.md` 与 ADR 0001 与实现一致。
  - 全仓 grep：不再有 `once` 字段残留（允许历史迁移 SQL 中的列名引用）；无 `console.log`/调试代码；无新增直接依赖。
  - 逐条把规格 US-01 ~ US-39 映射到测试或人工验收记录；无法执行的（如无真实 AI Key）明确标注，不用假 Key 冒充通过。

## 验收标准

- 规格中所有用户故事都有对应测试或明确的人工验收记录，没有未解释的缺口。
- 旧库启动、旧备份导入、导出再导入均成功；`once=true` 历史数据变为每日单点。
- 无场景、场景停用、静默、错过、推迟、强提醒、宠物全链路符合规格。
- AI 文本、混合、图片三条路径按环境验收；无 Key 时明确标注 parser + 手动路径的覆盖范围。
- `make test`、`make lint`、`make smoke` 通过；无新增依赖；文档同步完成。
- 全仓无旧 `once` API/UI/提示词残留，不再存在两套「一次性」语义。
