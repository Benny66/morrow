# AI 快速添加：文本 → 一次性草稿

**Blocked by**: 002

> 规格：US-21、US-22（一次性部分）、US-23、US-24、US-25、US-27、US-28、US-31、US-33

## 目标

用户在首页快速添加里输入一句自然语言，AI 生成可编辑的一次性草稿；确认后原子落库；未配置 AI 或调用失败时，手动创建入口仍然可用。

## 涉及层

- [ ] 数据层
  - 批量原子写入绑定：一次性草稿全部成功或全部回滚；复用 `normalizeReminderInput`，不绕过校验。
  - `GenerateQuickAddDrafts` 只接收文字（附件在 006）。
- [ ] 逻辑层
  - 新快速添加提示词/schema：只产出一次性草稿；携带当前本地日期、时间、时区；缺日期按「今天未到→今天，已过→明天」补全；显式过去日期拒绝；1–10 条；不强制「3–6 条」。
  - 新 parser（复用现有 JSON 容错能力）与固定时钟注入；草稿含 `once_at`（Unix）及展示所需字段；标题/正文/kind 归一化。
  - 服务层 `GenerateQuickAddDrafts`（不落库）+ 批量保存服务（事务）；绑定写入 `app.go`。
- [ ] UI 层
  - 首页快速添加：文本框 + 「AI 生成」按钮；保留「手动添加」入口。
  - 预览对话框：一次性草稿可编辑标题、正文、日期、时刻；可删除/逐条勾选；显示完整日期 + 时刻；确认后保存。
  - 错误展示：未配置 Key、网络失败、模型返回非法 JSON、过去时间等给出可读错误；手动入口不受影响。
- [ ] 测试
  - Parser fixture（固定 now）：单条/多条一次性；缺日期今天/明天；显式过去日期报错；代码围栏/前后废话；超长字段；0 条与超过 10 条。
  - 服务：批量保存全成或全不成；过去时间/超长/非法 kind 回滚整批。
  - UI：真实 AI（有 Key 时）输入「明天下午 4 点吃苹果」→ 预览 → 编辑 → 保存 → 即将到来；无 Key 时手动路径成功。
  - `make test`、`make lint` 绿。

## 验收标准

- 输入「明天下午 4 点吃苹果」→ 草稿显示完整日期 + 16:00；可改时间后保存；「即将到来」立即出现。
- 一句话包含多个一次性事件 → 多条草稿；全部合法才落库，任一条非法则整批不写。
- 显式过去日期 → 可读错误，不静默顺延、不落库。
- 未配置 Key/网络失败/非法 JSON → 可读错误；手动创建仍可用。
- 草稿未经确认不写库；确认后走同一校验路径。
- `make test`、`make lint` 通过。
