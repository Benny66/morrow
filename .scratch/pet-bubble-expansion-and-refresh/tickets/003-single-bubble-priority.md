# 宠物气泡单一化与优先级

**Blocked by**: 无

> 规格：A-6、5.2 T-05

## 目标

同一时刻只显示一个气泡：陪做 > 预警 > 暂停 > 待处理；倒计时期间不再出现待处理的完成/推迟按钮。

## 涉及层

- [ ] UI 层（`frontend/src/views/Pet.vue`）
  - 把待处理气泡从独立的 `v-if="bubbleVisible"` 改为 `v-if` / `v-else-if` 链的最后一支：
    `陪做（Countdown）→ 预警（Warning）→ 暂停 → 待处理`。
  - 确认倒计时期间只剩陪做气泡；预警、暂停同样不叠待处理气泡。
- [ ] 逻辑层
  - 不改数据与绑定；优先级是纯展示规则。
- [ ] 测试
  - 手动：触发 stand 休息提醒，在预警、倒计时、结束后三个阶段各截一次宠物窗口；每个阶段只有一个气泡。
  - 有一条待处理时进入暂停（会议/全屏）→ 只显示暂停气泡；暂停结束且仍有待处理 → 待处理气泡回来。

## 验收标准

- 倒计时期间宠物上只有一个「陪你休息 mm:ss」气泡，没有完成/推迟。
- 预警、暂停同样不叠气泡。
- 优先级顺序与 `CONTEXT.md` 一致：陪做 > 预警 > 暂停 > 待处理。
- 不改变任何气泡文案与按钮行为（除隐藏）。
