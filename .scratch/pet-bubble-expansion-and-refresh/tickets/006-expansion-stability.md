# 扩窗边界稳定：缩放、拖拽、多屏与收敛

**Blocked by**: 005

> 规格：A-9、A-10、A-11、A-13、A-14；5.2 T-03/T-10/T-14

## 目标

把扩窗在真实操作中的边界收干净：改缩放、拖动中到点、副屏、夹窄后的二次测量、窗口不抢焦点。

## 涉及层

- [ ] 逻辑层（Go）
  - `SetPetSettings` 在扩窗中改缩放：基础尺寸更新后保留气泡预算，按新宠物高度重算总高；底边锚定。
  - 工作区选择固定为「宠物脚底所在屏幕」；跨屏时不落到主屏。
  - 若某平台 `SetSize` 会置前/抢焦点，记录平台并降级（不静默）。
- [ ] UI 层（`frontend/src/views/Pet.vue`）
  - 手势期间（`petPressed` / 拖拽）不调用扩窗；松手后补一次测量（A-12）。
  - 收敛守卫：记录上次上报的 `(visible, total)`；相同值不重复调用；宽度被夹窄后由 `ResizeObserver` 触发第二次测量，稳定后不再回调。
  - 缩放设置变化后主动重测一次（宠物高度变了，气泡高度未必变，`ResizeObserver` 抓不到）。
  - 扩窗/还原不 `Focus()`、不把宠物置前。
- [ ] 测试
  - 手动：扩窗可见时设置页 0.5 → 1.0 → 2.0；气泡始终完整，宠物不跳出屏幕。
  - 拖动宠物过程中触发提醒；宠物不跳、不抢鼠标；松手后气泡完整。
  - 副屏触发提醒；气泡落在副屏工作区，不被主屏边界截断。
  - 屏幕右缘 + 夹窄：最多两次调整后稳定；日志无 resize 刷屏。
  - 其他应用输入时触发提醒；输入焦点不跳走。

## 验收标准

- 上述手动用例全部通过；无反复 resize 的日志刷屏。
- 缩放切换后底边坐标不变，气泡仍完整。
- 无新增绑定/事件；004 的几何单测仍全绿。
- 平台降级有记录、有日志，不静默。
