# 全量验收与文档收口

**Blocked by**: 001、002、003、004、005、006

> 规格：全部用户故事；重点 5.2 T-01～T-15、5.3 完成定义

## 目标

在真实休息提醒、宠物缩放三档、贴边/多屏、退出重启等场景完成累积验收，并收口文档与静态检查。

## 涉及层

- [ ] 逻辑层
  - 累积审计 001 的结算路径与 002 的自愈是否互相掩盖：人为删掉 `changed` 广播后，自愈仍能让气泡消失，但日志会出现失败请求；确认根因修复存在，而不是被兜底掩盖。
  - 确认没有新增事件常量、没有第二套气泡优先级或窗口尺寸规则。
- [ ] UI 层
  - 逐条走查规格 T-01～T-15：
    - 0.5 / 1.0 / 2.0 气泡完整；宠物原位；消失还原；
    - 贴右缘 / 顶部 / 副屏；
    - 贴边收起 / 展开；
    - 退出重启；
    - 倒计时单气泡；自然结束与提前完成；
    - 自愈、真失败、连点；
    - 缩放切换、拖动中到点。
- [ ] 测试与文档
  - `make test`、`make lint`、`make gen`（无 diff）、`make smoke` 全绿。
  - 全仓 grep：无 `console.log`、无调试残留、无新增直接依赖。
  - `docs/map.md` 补新文件（若新增）；`CONTEXT.md` 与 ADR 0007 与实现一致。
  - 把规格 T-01～T-15 映射到测试或人工验收记录；无法执行的平台明确标注，不冒充通过。

## 验收标准

- 规格中所有用户故事都有测试或明确的人工验收记录，没有未解释的缺口。
- 根因（`changed` 缺失）与兜底（自愈）各自可分别验证；删掉 `changed` 时能观察到区别。
- `make test` / `make lint` / `make smoke` 通过；绑定产物无过期；文档同步。
- 工作区无调试代码、无新增依赖。
