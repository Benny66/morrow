# 009 — 记忆事实、完整文案与「别这样说」

**Blocked by**: 006、008、003

**状态**: 已完成（2026-10-22；真实 GUI 记忆句/语气切换验收）

> 规格：`docs/specs/2026-10-22-sit-awareness-and-sassy-pet.md` 的 D-2、D-4–D-8、7.6、F-6。
> 本票让宠物开始「记得」；独立记忆气泡留给 010。

## 目标

宠物能在软提醒或欢迎回来时引用一条类别级记忆/完整统计（例如「你最近下午容易连坐」「这周主动起身比上周多」），默认毒舌，用户点「别这样说」立即切到温和并持久化。所有文案来自内置模板 + 变量，不调 AI。

## 涉及层

- [x] 逻辑层：`internal/sit/memory.go`
  - 派生事实（按本地日期）：时段久坐、星期规律、最长连续、休息次数/类型、主动起身次数、类别分钟数、跳过/推迟次数、正向/负向周对比。
  - 只使用类别级会话与聚合，不回放原始应用流水；不出现应用名。
  - `SelectQuote(now, facts, tone, history)`：按时段相关性、近期未重复（3 天内）选择模板；没有值得说的事实时不生成。
  - 机会：软提醒、欢迎回来、专注结束（008 暴露的状态）；本票不新增独立气泡。
- [x] 逻辑层：`internal/sit/template.go`
  - 三档语气完整模板：毒舌 / 活泼 / 温和；覆盖软提醒、欢迎回来、静音确认、语气确认、记忆句。
  - 毒舌可引用任何统计；硬禁区：外貌、智力、心理、家庭、健康、医疗诊断；每句软提醒必须有动作/台阶。
  - 模板常量可被内容护栏扫描；同一模板短期不重复。
- [x] 逻辑层：`sit_runtime.go` / `app.go`
  - `SetSitTone(tone)` 持久化并让下一次气泡生效；「别这样说」调用后给一句温和确认。
  - 软提醒/欢迎回来文案可带一句记忆；不额外消耗主动发言预算（它仍是同一条气泡）。
  - 画像关闭时没有类别记忆，只可使用时间型事实（或退回 003 的基础文案）。
- [x] UI 层：`Pet.vue` / `Settings.vue`
  - 软提醒与欢迎气泡显示记忆句；「更多 > 别这样说」在毒舌/活泼下可见。
  - 设置语气切换与宠物实际文案一致；重启保持。
  - 不新增独立记忆气泡；动作仍是 003 的三动作 + 更多。
- [x] 测试
  - memory：事实派生、时段/星期、正向/负向对比、3 天去重、无应用名、无事实不生成。
  - template：三档语气、每个软提醒动作齐全、硬禁区词扫描、无 AI/网络依赖。
  - tone：别这样说→gentle 持久化；设置切换；重启保持；软提醒/欢迎文案跟随。
  - budget：记忆句不额外占一次主动发言。
  - `make test` / `make lint`。
- [x] 文档：`docs/pet-character.md` 人格与三档语气；`CONTEXT.md` 记忆引用校对；内容审校记录。

## 验收标准

- 有足够历史时，软提醒/欢迎回来能出现一条类别级记忆句；同一事实 3 天内不重复。
- 默认毒舌；「别这样说」立即切温和并持久化；设置可切回；重启保持。
- 毒舌不出现身份/健康攻击，不做医疗诊断；每个软提醒都有可执行动作。
- 不说应用名；不调 AI；断网可用；同一输入固定输出。
- 画像关闭时没有类别记忆，基础模式仍可正常冒泡。
- 不新增独立记忆气泡；留给 010。
- `make test` / `make lint` 通过；真实 GUI 与内容审校记录。
