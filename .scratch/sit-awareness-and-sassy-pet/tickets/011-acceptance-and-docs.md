## 目标

把 003–010 串成一条可交付的用户旅程：同意画像 → 久坐提醒 → 起身/抵扣 → 专注克制 → 记忆/毒舌 → 久坐页核对 → 关闭/清空/导出。完成 macOS/Windows 手工验收、隐私抽查、内容审校与文档更新。

- 审计发现已修复或已登记后续 ticket；`index.md` 状态更新。

### macOS 手工验收（详见 003–010 各票记录）

- 干净安装四步引导，开启画像/基础检测/跳过三条路径；升级一次性卡片；默认毒舌披露。
- 60/90 软提醒、snooze、今天先这样、阈值/语气设置（003 自动化 + GUI）；主动休息 credited、下一次 stand silent（004 GUI）；真实锁屏 paused=lock、启动收尾（006 GUI）。
- 应用采样/会话明细/类别分布/关闭保留删除、类别纠正/按日/导出 include-exclude/清空保留 CheckIn（006/007 GUI）；专注接线（008 临时 2 秒阈值 GUI + 真实阈值单测）。
- 记忆句、三档语气、别这样说/重启保持、独立 memory 气泡/预算/Ack/静音抑制（009/010 GUI）。

### 隐私、内容与性能

- 日志抽查：应用会话/类别/文案错误路径不再输出 SQL 字面量；日志只保留表结构、模板 ID、记忆 ID、提醒 ID 与错误。
- 导出副本 POSIX 0600；数据库 0600；无新增摄像头/屏幕录制/辅助功能权限；画像关闭时不查询应用会话。
- 毒舌模板内容护栏扫描硬禁区、应用名与软提醒动作齐全性；人工审校 `docs/pet-character.md` 的人格边界。
- 采样只在画像开启/场景生效/未锁屏长空闲时读取；应用会话按切换落库、心跳 ≤1/分钟；久坐心跳 1/分钟；无 5 秒写库。1 小时 CPU 长跑未做，转 012。

### 审计发现与修复

1. SQL 慢查询/错误日志会带出插值字面量（可能含应用标识/宠物文案）——新增单/双引号字面量脱敏与测试。
2. 崩溃后开放久坐会话未收尾——新增 `RecoverOpenSitSessions`，按最后心跳钉结束时间并保留 active_seconds；测试覆盖日累计。
3. 恢复数据库后 Tracker/采样可能仍指向旧会话——导入前停运行时，成功后收尾备份中的开放会话、重置内存态并重启；新增重置单测。
4. README 仍写三步引导、把温和作为历史定位；CONTEXT 引导定义仍为三步；pet-character 把已实现的芽耷拉列为未实现——已同步为四步、默认毒舌、芽耷拉已实现。
5. 设置页 Windows 锁屏能力文案过于绝对——改为「部分受限终端可能只能读空闲」，README 记录同一限制。
6. 文档新增 `openspec/specs/sit-awareness/spec.md` 能力基线；README 增加久坐感知/毒舌健康搭子、隐私边界与四步引导。

### 转 012 的已知验收缺口

- Windows 实机：应用采样、Win+L、锁屏抵扣门槛、安装包/单实例。
- macOS 长跑：60/90 分钟软提醒、真实锁屏 ≥5 分钟 + 已坐 ≥30 分钟抵扣、10 分钟真实专注墙钟、1 小时 CPU/能耗、5 次预算与 30 分钟间隔压满。
- 「打开客户端」按钮的真实主窗聚焦点击；内容模板长期用户审校。
