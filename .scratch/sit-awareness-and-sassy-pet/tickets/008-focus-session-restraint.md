# 008 — 专注会话与更克制的提醒时机

**Blocked by**: 006、003

**状态**: 已完成（2026-10-22；真实 GUI 专注接线 + 单测阈值）

> 规格：`docs/specs/2026-10-22-sit-awareness-and-sassy-pet.md` 的 B-4、C-2、D-9、E-4（当前专注）、7.2。
> 本票只改「宠物何时开口」；不改久坐时钟、不改正式提醒。

## 目标

用户在同一个应用连续专注时，久坐软提醒不出现；切出应用或输入停顿后，如果仍满足阈值与空档条件，再冒一次。正式提醒仍按原计划与既有自然停顿顺延处理。

## 涉及层

- [x] 逻辑层：`internal/sit/focus.go` / `tracker.go`
  - 专注会话：同一应用连续使用 ≥10 分钟；短暂切走 ≤120 秒不打断；切走 >120 秒或进入另一类别结束。
  - 只用应用身份与时间；不读窗口标题/内容；不改变久坐时钟。
  - `Snapshot.Focus` 返回类别 + 已专注分钟；**不返回应用名**。
  - 专注期间 `Policy` 抑制久坐软提醒与记忆气泡；正式提醒不抑制。
  - 专注结束（切出/停顿）作为一个机会点，交给 009 的记忆策略；本票先暴露状态。
- [x] 逻辑层：`sit_runtime.go`
  - 采样器把前台应用变化/时长喂给 tracker；画像关闭时 `focus=nil`，退回输入停顿等待。
  - 保持 5 秒采样；不新增轮询。
- [x] UI 层：
  - `Sit.vue` 今日区增加「当前专注：类别 + 分钟」（画像开启时）；无专注时显示「—」。
  - 宠物气泡在专注期间不出现；切出后按 003 的优先级/预算显示。
  - 宠物文案只用类别，不出现应用名。
- [x] 测试
  - tracker：同一应用 40 分钟 → focus；切走 90 秒 → 继续；切走 3 分钟 → 结束；切到另一类别 → 结束；画像关闭 → nil。
  - policy：专注中不生成软提醒；切出后满足条件才生成；正式提醒不受影响；预算/Ack 不变。
  - snapshot/页面：focus 字段无应用名；当前专注显示/清空。
  - `make test` / `make lint`。
- [x] 文档：`CONTEXT.md` 专注会话语义校对；`Sit.vue` 文案说明。

## 验收标准

- 画像开启且在 IDE 连续 40 分钟：没有久坐软提醒；宠物情绪仍可变化。
- 切到浏览器并停顿后，若仍超阈值且 15 分钟内无 stand/move，出现一次软提醒；否则让正式提醒承担。
- 短暂切到浏览器查资料 90 秒再切回，专注会话不打断；切走 3 分钟后原会话结束。
- 正式提醒、智能免打扰、自然停顿顺延行为不变。
- `Snapshot.Focus` 与宠物气泡不含应用名；页面只显示类别与分钟。
- 不新增依赖；`make test` / `make lint` 通过；真实 GUI 走查记录。

## 实现记录（2026-10-22）

- 领域层：新增 `internal/sit/focus.go`（`FocusMin=10m`、`FocusSwitchGrace=2m`）；Tracker 内部保存应用标识、类别、累计专注时长与离开时刻，Snapshot.Focus 只输出 `{category, minutes}`，不足 10 分钟或结束时为 nil。专注不推进久坐时钟；真实休息/锁屏/切场景/关闭画像都会清除专注。
- 宽限语义：同一应用累计 10 分钟进入专注；切走 ≤120 秒不打断，离开期间不累计分钟；超过 120 秒或持续不在原应用则结束。短切到浏览器查资料不会打断（与 B-4 验收一致），长期离开才结束。
